## Feature summary

Priya Chen (developer-as-user) points an existing ASP.NET Tasks API at the emulator. The **existing** FederationMetadata URL grows a WS-Fed `RoleDescriptor` (both `PassiveRequestorEndpoint` and `SecurityTokenServiceEndpoint` = `/{tid}/wsfed`, same signing cert as `IDPSSODescriptor`). `GET|POST /{tid}/wsfed` answers `wa=wsignin1.0` with the same account picker as OIDC/SAML. After account choice, the browser POSTs a SAML 2.0 `wresult` (RSTR) to a registered `wsfed-reply`. Unmodified `Microsoft.AspNetCore.Authentication.WsFederation` completes that path (`e2e/wsfed`).

**Quality #1:** auditability — wrap `/{tid}/wsfed` with flow `wsfed`; `ClientID` is `wtrealm`; never persist or log `wresult`.

**North star (KPI-1):** `python3 e2e/run.py wsfed` green.

**Parity:** `docs/parity.md` WS-Federation row is 🟢 Real (do not revert).

**Out of this cut:** SOAP / active WS-Trust, `/common/wsfed`, SAML 1.1, witnessed `wsignout1.0`, MFA/CA, encryption, portal gallery, IdP-initiated / unsolicited login.

## Business context

The emulator already served OIDC and SAML. FederationMetadata was SAML-only; `/{tid}/wsfed` was unrouted (404). `Microsoft.AspNetCore.Authentication.WsFederation` could not find a `PassiveRequestorEndpoint` or complete sign-in.

DISCOVER G1 still fails the 5-interview rule (count = 1). Demand is a named class, not usage-validated. The cut proceeded on a protocol gap plus a locked stranger, not padded interviews.

## Lessons learned

1. **Spike before stories when TokenType is conflicted.** SharePoint docs say SAML 1.1; the locked ASP.NET `Wtrealm=api://…` witness is SAML 2.0. Guessing in DISCUSS would have minted the wrong assertion.
2. **SAML analog, not SAML alias.** Different binding and envelope. Type-filtered `wsfed-reply` is required; `HasRedirectURI` ignores type and would POST to ACS/`web` URLs.
3. **Auditability before stranger-only success.** KPI-1 is required and is not a substitute for the existing recorder (`Flow=wsfed`, never log `wresult`).
4. **This repo’s architecture SSOT is `docs/product/`.** Finalize must not invent `docs/adrs/` or `docs/architecture/ws-fed/` copies.
5. **Go mutation is not available** in this nWave install. Skip with a written report rather than a fake kill rate.
6. **DEVOPS is optional when CI already exists.** Adding `wsfed` to the existing sdk-e2e matrix was enough.
