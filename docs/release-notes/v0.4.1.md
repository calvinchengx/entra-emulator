# entra-emulator v0.4.1

A maintenance release. Nothing in the emulator's behaviour changes: no new
endpoint, no altered response, no seed data touched. Consumers pinned to v0.4.0
can move to v0.4.1 without re-reading anything, and can equally stay where they
are.

## Dependencies

One grouped update covering six Dependabot PRs (#42–#47, landed as #48):

- `modernc.org/sqlite` v1.55.0 → v1.56.0, applied across **all four Go
  modules**. Bumping only the root module is what left #34 half-fixed, so the
  e2e modules move together with it now.
- `modernc.org/libc` v1.74.1 → v1.74.4 and `mattn/go-isatty` v0.0.20 → v0.0.24,
  both indirect.
- Docs and portal toolchain: `astro` / `@astrojs/starlight` 0.41.5 → 0.41.7,
  `vite` 8.1.5 → 8.2.0, `@playwright/test` 1.62.0 → 1.62.1. `portal/dist` is
  rebuilt for vite 8.2.0, so the committed bundle matches a fresh build.

## Docs

The v0.4.0 release notes are now in the repository, not only on the releases
page — `docs/release-notes/v0.4.0.md`.

## Upgrading

Nothing to do. The tenant and every seeded object id are unchanged from v0.4.0;
if you migrated for that release, you are already done.
