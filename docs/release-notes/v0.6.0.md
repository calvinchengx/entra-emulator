# entra-emulator v0.6.0

The release that stopped taking its own word for it. Every 🟢 row in
`docs/parity.md` binds to a witness, and until now a third of them were
witnessed by our own Go tests — our client on both ends of our own
implementation. Pointing **real** clients at those rows found seven interop
defects and one data-loss bug, none of which our tests could see, because the
test and the code shared the same assumption.

Independently-evidenced parity went from **27/51 (53%) to 43/54 (80%)**.

## SAML 2.0 SP-initiated SSO

A second protocol, not a variation on the first. The emulator now serves the
SP-initiated flow end to end and is driven in CI by `node-saml`, an unmodified
third-party service provider, so the assertion it signs verifies in software
that knows nothing about this project.

## The defects real clients found

Each of these passed our own tests and failed a real client:

- **`private_key_jwt` was unusable from MSAL Go.** Five Go tests passed while no
  Microsoft Go client could authenticate at all: MSAL signs client assertions
  with **PS256** and the emulator verified only RS256.
- **ROPC was unreachable from MSAL Go.** It probes `/common/UserRealm` before
  attempting, and a 404 made it give up before sending credentials.
- **Custom API scopes were unusable end to end.** Clients send
  `api://<app>/<scope>`; the emulator echoed the short name, and the narrowing
  check then compared two different vocabularies.
- **The group-overage pointer was dead twice over.** The payload directs a
  client to `getMemberObjects` to recover groups the token could not carry —
  that route did not exist, and the URL was built without the compat prefix.
- **SCIM discovery advertised routes it did not serve.** `/ResourceTypes/{id}`
  and `/Schemas/{id}` were unrouted while every `meta.location` pointed at them,
  and `/Schemas` carried no `attributes` at all, so no client could learn that
  `userName` is required. An independent RFC checker scored the endpoint
  **3 passed / 31 errored** on first contact, against a row already graded 🟢.
- **SCIM PATCH silently did nothing** for `name`, `emails` and `externalId`, and
  `remove` was a no-op returning `200 OK` — the worst failure mode, because it
  looks like success.
- **Incremental provisioning lost changes.** The watermark is Unix seconds and
  compared with `<=`, so a change committed in a sync's own second was skipped
  on that sync and every one after it. Not delayed: lost.

## SCIM, made conformant and witnessed in both directions

Inbound now serves discovery by id with real attribute definitions, `externalId`
with correlation, RFC 7644 attribute projection, `POST /.search`, and PatchOp
paths that actually apply. Unset attributes are omitted rather than emitted
empty, so a client can tell a removal happened.

Both directions are witnessed by third parties: inbound by
[`scim2-tester`](https://github.com/python-scim/scim2-tester), an independent RFC
7643/7644 checker, and outbound by
[`AzureAD/SCIMReferenceCode`](https://github.com/AzureAD/SCIMReferenceCode) —
Microsoft's own reference service provider, receiving the full Entra sequence:
filter-probe, create, `externalId` correlation and `active:false` deprovision.

## Witnesses added

Token signing and key rotation (validated by `Microsoft.IdentityModel`, the stack
ASP.NET Core uses), instance discovery, the Graph permission gate, consent,
workload identity federation, group overage, `wids`, logout in a real browser,
and persistence across an actual emulator restart.

## Differential evidence against Entra

The golden reference was captured once and had been the unquestioned authority
since. A weekly job now checks it against Entra's **live** discovery document and
opens an issue on drift, distinguishing "unreachable" from "matches" so an outage
cannot read as a pass.

It immediately found one: the emulator advertises
`request_uri_parameter_supported: true` where Entra answers **false**. The
capability is real and deliberate, and is now recorded as a **divergence rather
than parity**, because a client relying on it here will fail against Entra.
