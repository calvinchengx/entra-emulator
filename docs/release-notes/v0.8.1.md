# entra-emulator v0.8.1

Mint Azure Databricks-audience tokens without a resource app.

`2ff814a6-3304-4ab8-85cb-cd0e6f879c1d` is the well-known first-party Azure
Databricks app id. databricks-emulator accepts federated JWTs only when `aud`
is this value. Like Fabric, this is a compile-time carve-out — no resource
app is seeded in the directory.

```sh
curl -sk -X POST "https://localhost:8443/$TENANT/oauth2/v2.0/token" \
  -d grant_type=client_credentials \
  -d client_id=00d88624-f0d7-46f6-a641-6232c2608928 \
  -d client_secret=daemon-app-secret \
  -d scope=2ff814a6-3304-4ab8-85cb-cd0e6f879c1d/.default
```

The family chain is the published-image witness: that token opens
databricks `/Me`.

## Upgrading

Nothing to migrate. Tenant and seeded object ids are unchanged from v0.8.0.
